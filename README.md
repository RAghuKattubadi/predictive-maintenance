This project builds a predictive maintenance classification system on 10K manufacturing sensor records. Using operational signals like temperature, torque, rotational speed, and tool wear, the pipeline detects machine failures before they occur. Key techniques include SMOTENC for handling class imbalance, Stratified K-Fold cross-validation, RandomizedSearchCV for hyperparameter tuning, and custom thermal stress and sensor-derived feature engineering — achieving 80% recall on the minority failure class.
